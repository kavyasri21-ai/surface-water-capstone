# Week 4: Modeling and Trend Analysis
This week focused on analyzing contaminant trends and testing whether contaminant concentration changes over time.
Work completed:
- Created trend plots for top contaminants
- Performed detailed nitrate analysis
- Applied regression models to study trends
- Conducted exceedance analysis using MCL values
- Identified outliers in contaminant data

Key observation:
Regression results showed that year alone does not explain variation when all contaminants are combined, highlighting the importance of contaminant-specific analysis.
